# Twinline

Two drum machines. One booth.

Amber is a sample machine. Lacquer is an FM synth. They share a clock, a crossfader, and a 16-step mix track that records channel faders, EQ, filters, and the crossfade.

## Run

```bash
npm install
npm run dev
```

Press play to arm the audio. Patterns and mix locks stay in the browser.
